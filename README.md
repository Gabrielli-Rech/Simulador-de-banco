## 🏦 Simulador de Banco

Este projeto simula operações bancárias em um ambiente de terminal, utilizando Java. Ele foi desenvolvido para praticar conceitos de orientação a objetos, como herança, polimorfismo e exceções personalizadas.

## 🚀 Funcionalidades

Abertura de Conta Corrente e Poupança: Crie contas com saldo inicial.

Depósitos e Saques: Realize operações de crédito e débito.

Transferências: Transfira valores entre contas.

Exceções Personalizadas: Tratamento de erros como saldo insuficiente.

## 🧱 Tecnologias Utilizadas

Linguagem: Java

Paradigma: Orientação a Objetos

Estrutura: Classes e objetos
